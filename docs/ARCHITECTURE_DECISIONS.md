# Архітектурні рішення

* **AD-1 Модульний моноліт** FastAPI + SQLAlchemy 2 (sync) + PostgreSQL. Sync обрано для простоти й `SELECT … FOR UPDATE`; async — коли з'явиться потреба.
* **AD-2 Шари:** `api/` (HTTP) → `services/` (бізнес-правила) → `models.py`. Помилки домену (`core/errors.py`) мапляться в HTTP в одному місці.
* **AD-3 ML-порт** (`app/ml/ports.py`): бізнес-код залежить лише від Protocol. Правило безпеки T-04 застосовується до і після ML; вихід ML санітизується (невідомі/заборонені tour_id відкидаються).
* **AD-4 Mock заборонений поза dev/test** — валідація конфігу; відповіді mock позначені `is_mock`.
* **AD-5 Картка каталогу = виїзд (departure)**, бо на вайфреймі дата й «Book Now» на картці.
* **AD-6 Місця:** зайняті = confirmed + pending з неспливлим hold; перевірка під блокуванням рядка виїзду. Протухлі hold не потребують фонового джоба (рахуються лениво), статус `expired` проставляється при зверненнях.
* **AD-7 Автентифікація:** JWT (HS256, фіксований алгоритм, exp/iss обов'язкові), Argon2. Refresh-токенів немає (MVP).
* **AD-8 Валідація:** `extra=forbid` на всіх входах; https-only URL; ролі не приймаються від клієнта.
* **AD-9 Гроші:** цілі гривні (`price_uah`); копійки/ПДВ — за потреби окремим рішенням.

## Відомі прогалини безпеки
Немає rate limiting (робити на gateway/ `slowapi`), немає відкликання токенів, немає підтвердження email, немає аудит-логу. Перед продакшном — закрити.
